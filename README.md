# Projeto Integrador: Análise do ENEM (Assis-SP) 

**Autor:** Gabriel Marchetti Motta
**Disciplina:** Projeto Integrador Extensionista em Ciência de Dados

## Sobre o Projeto
Este repositório contém os artefatos do projeto de análise do desempenho de alunos de escolas públicas e privadas da cidade de Assis-SP, utilizando os microdados do ENEM. O objetivo é identificar defasagens educacionais e fornecer insights para professores e cursinhos populares da região.

## Ética e LGPD 
Este projeto utiliza **dados públicos** fornecidos pelo INEP. Todos os dados são previamente anonimizados na fonte, não contendo nomes, CPFs, endereços ou qualquer informação que permita a identificação pessoal dos candidatos. O projeto está 100% em conformidade com a Lei Geral de Proteção de Dados (LGPD).
